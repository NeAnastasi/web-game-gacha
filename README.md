# Новогодняя веб-игра 

Новогодний интерактивный сюрприз для подписчиков Telegram-канала - веб-игра с механикой открытия случайных карточек и возможностью собирать коллекцию.

Проект был создан как подарок для реальной аудитории: игроки накапливают валюту через кликер, открывают карточки разной редкости и могут открыть секретные карты при выполнении особых условий.

---

## Технологии

- **HTML, CSS, JavaScript** - вся логика и интерфейс
- **LocalStorage** - сохранение прогресса на стороне клиента

---

## Игровая механика

- **Кликер** - накопление валюты для получения карточек
- **Два режима получения карточек** - 1 карточка (15 кликов) или 10 карточек (150 кликов)
- **Три уровня редкости** - обычные, редкие и легендарные карты
- **Система гаранта (pity)** - легендарная карта гарантированно выпадает после 60 неудачных попыток
- **Секретные карты** - открываются при накоплении 5 легендарных карт одного персонажа

---

## Визуальные и звуковые эффекты

- Анимации выпадения карточек 
- Световые вспышки в зависимости от редкости (синяя, фиолетовая, золотая)
- Звуковое сопровождение - фоновая музыка и звук при выпадении легендарной карты
- Парящие шары, снег на фоне - создают праздничное настроение
- Адаптивный интерфейс - удобно играть и с телефона

## Запуск проекта

Проект полностью клиентский, работает в браузере без сервера.
Достаточно открыть файл index.html в браузере.
